# 카메라 / 조명 노트

본 POC는 실제 광학계 / 조명 장비를 갖추지 못한 환경에서 만든 것이므로, 실측 데이터 대신 합성 이미지를 사용한다. 그럼에도 채용 직무에 명시된 **“2D/3D 광학계 및 조명 테스트”** 항목과 연관 지어, 본 프로젝트가 가정한 광학 조건과 한계를 정리한다.

## 조명 불균일이 임계처리에 미치는 영향

- 전역 단일 임계(Otsu)만 쓰면 강한 측면광 환경에서 “밝은 쪽 결함은 누락 / 어두운 쪽 정상 영역은 결함으로 오인” 같은 비대칭 오류가 잘 난다.
- 본 엔진은 이를 완화하기 위해 **CLAHE**(타일 8×8, clipLimit 2.0)를 사용한다. 타일 단위로 히스토그램을 클립하므로 광원 위치 차이에 따른 영향이 줄어든다.
- 조명이 더 심하게 불균일할 경우 `adaptiveThreshold(ADAPTIVE_THRESH_GAUSSIAN_C)`를 추가하거나, “정상 표면 평균치를 모델링한 background subtraction”을 결합하는 식으로 확장이 가능하다.

## 반사광 / 하이라이트로 인한 오검출

- 도장면 / 금속 표면은 정반사가 강해서 카메라 각도에 따라 흰색 하이라이트가 결함처럼 보일 수 있다.
- 본 엔진은 Otsu가 “밝은 쪽 픽셀”까지 결함으로 잡지 않도록 `THRESH_BINARY_INV`를 사용해 어두운 쪽만 결함 후보로 본다. 다만 검사 대상이 “밝은 결함 위주”일 경우 임계 부호를 바꿔야 한다.
- 실제 설비에서는 **편광 필터(Polarizer)** 또는 **dome light** 같은 확산 조명으로 정반사를 줄이는 것이 일반적이다.

## 실 설비 적용 시 조명 검토

| 조명 유형 | 적합 검사 대상 | 비고 |
| --- | --- | --- |
| Coaxial light | 평면 금속, 글래스 | 정면 입사로 표면 결함의 그림자를 살리기 어려움. 거울면 검사용 |
| Dome light | 곡면 도장, 굴곡 표면 | 정반사 억제, 균일 조명. 본 POC가 가장 가까이 가정한 형태 |
| Line scan + Bar light | 연속 strip / 인쇄물 | 고해상도 라인 검사. 본 POC 범위 밖 |
| Dark field / Low-angle light | 미세 스크래치, 점 결함 | 결함이 강하게 부각됨. 스크래치 모드에서 시너지 |
| Structured light / 3D depth | 단차 결함, 함몰, 돌출 | 2D 카메라로 잡기 어려운 결함. 향후 확장 |

## 본 프로젝트의 한계

- 카메라 캘리브레이션을 수행하지 않았다. `pixel_to_mm_ratio`는 사용자가 외부에서 측정해 넘긴다는 전제이다.
- 광원 셋업 / 노출 시간 / 게인 같은 캡처 시점 파라미터는 본 엔진의 책임 범위 밖이다.
- 합성 이미지의 노이즈/조명 모델은 실제 도장면의 specular highlight를 완벽히 재현하지 못한다. 실 환경 검증 시 추가 튜닝이 필요하다.
